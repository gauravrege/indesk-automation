## What Was Done

Developed a Python-based Resume Scraper to automate the extraction of key information from bulk resume files.

## Technical Execution

- **Document Parsing:** Built a parser using Python to read both PDF and Word (`.docx`) resume formats.
- **Data Extraction Logic:** Engineered an extraction module to pull out crucial candidate information such as name, contact details, skills, and experience.
- **Excel Export:** Integrated an exporter to compile all parsed data into a structured Excel (`.xlsx`) format, transforming a folder of unstructured resumes into an easily searchable database.
- **Automation:** Packaged the tool into a standalone batch file (`run_scraper.bat`) allowing non-technical HR personnel to simply double-click and run the pipeline on their folder of resumes.

## Impact

> By automating resume processing, I eliminated the manual effort required to read and summarize hundreds of resumes, creating a streamlined, searchable database for recruitment and screening.
